12. NODE.JS STANDARD LIBRARY MODULES
────────────────────────────────────────────────────────────
The following built-in Node.js modules are used.
These are part of the Node.js runtime (MIT License).

- crypto       — Token and secret generation
- fs           — File system operations
- path         — Path handling
- url          — URL parsing
- stream       — Stream handling
- http         — HTTP server (via Express)
- os           — OS detection in installers
- events       — Event emitter

────────────────────────────────────────────────────────────
13. EXTERNAL SERVICES — OPERATOR-CONFIGURED
────────────────────────────────────────────────────────────
The following external services are called only when
configured by the operator. None are required defaults.

BlockCypher API  — BTC on-chain monitoring
Etherscan API    — ETH/USDT on-chain monitoring
Infura/Alchemy   — ETH RPC provider (operator choice)
Helius/QuickNode — SOL RPC provider (operator choice)
AcerbE™          — Asset fingerprinting (local or API)

14. DATA STORES
────────────────────────────────────────────────────────────
Name:             rapax.db
Type:             SQLite3 (via sql.js WebAssembly)
Location:         Operator-controlled local directory
Contents:         Products, transactions, payment addresses,
                  fingerprints, deliveries, audit log,
                  operator sessions.
Transmission:     None. Never transmitted externally.
Access Control:   Operator responsibility.

Name:             storage/products/
Type:             Filesystem directory
Contents:         Operator-uploaded product files.
Transmission:     None directly. Files delivered via
                  tokenized expiring download links.

Name:             storage/fingerprinted/
Type:             Filesystem directory
Contents:         AcerbE™-fingerprinted output files.
Transmission:     Delivered via tokenized download only.
